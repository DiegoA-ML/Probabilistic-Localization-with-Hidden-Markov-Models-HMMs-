# Probabilistic-Localization-with-Hidden-Markov-Models-HMMs-

Description:  This project aimed to predict a robot's location in a 16x4 grid environment with noisy sensor data using Hidden Markov Models. 

## The approach included:

	•	Techniques Used: Filtering, smoothing, and the Viterbi algorithm for probabilistic reasoning.
	•	Tools and Libraries: Python, NumPy, Matplotlib, Seaborn, and Pandas for simulations and data visualization.


## Key Results:
	•	Simulated 10-step robot movement with a success rate of 90% in accurately predicting locations using filtering.
	•	Generated heatmaps showing the robot's most probable positions, achieving high alignment between predictions and actual paths.
	•	Demonstrated robust handling of sensor noise with only 10% error rate, ensuring reliable trajectory predictions.
	•	Accurately modeled transitions across 42 states in the grid, providing real-time and historical positional insights.
